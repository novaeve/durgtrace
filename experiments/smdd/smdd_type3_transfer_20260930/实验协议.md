# SMDD Type3 DeepSeek high，2026-09-30

52题，三种方法：官方基础 harness baseline、ChatDrug Type3迁移、AgentDrug Type3迁移。所有请求固定 deepseek-v4.1-flash、enable_thinking=true、reasoning_effort=high、temperature=1。

官方仓库 https://github.com/t7rs/SMDD-Bench ，commit 359ef1d7c042b85fc1c544662b4fd6fb381f346f。任务来自官方 Hugging Face tasks_4_4_final.tar.gz 的本地副本。使用全部52题，不读取历史Claude输出。

Baseline 原 agent_loop、prompts、tools、config 文件保持不变；API传输注入 high 参数并补回工具调用的 reasoning_content。工具执行运输由 Docker 改为 Bubblewrap 加已有 evaluator_rootfs，Python工具无网络、只挂载公开 complex.pdb、reference.sdf 和本题工作区。Boltz在宿主已有兼容GPU环境执行，保持官方10样本默认值、seed42、max_parallel_samples2，保留结构和置信结果。ADMET用rootfs内环境。预算100轮、累计1000万token、8次Boltz、15次ADMET均保持官方值。

ChatDrug沿Type2迁移中的作者conversation/ReDF函数，单SMILES输入输出适配，最多3次生成。原参考库不能认证Type3的三维相互作用成功条件，沿原无合格参考退出路径；不伪造成功标签或添加专家检索候选，通常1次生成。

AgentDrug沿Type2迁移中的冻结run_core，最多4次生成；保留SMILES合法性检查和修订提示。将不适用的原固定LogP/QED等任务反馈块换成合法性和“Type3完整正确性未知”，不读取评分答案或将隐藏评分反馈给模型。此为任务迁移版本，不声称完整复现原论文任务上的算法效果。

两个编辑agent收到相同完整公开PDB/SDF文本，不裁剪坐标。baseline通过Python读相同去标识文件。三组工具能力和调用次数不同，不作为等预算消融。

按用户要求开启high，两个编辑agent的max_tokens统一32768（思考+输出），替代旧AgentDrug非思考模式的256上限，避免把high思考截断为无答案。任何截断均保留finish_reason与原响应，不按成功率重抽。baseline仍沿官方无单次显式上限。temperature沿此前Type2迁移设为1。

独立评分执行官方EvaluationRunner及metrics，不改阈值；Boltz传输返回全部预测CIF/置信/亲和力文件。参考gt_results的520个CIF仅供评分，不挂载进baseline，也不放进编辑agent提示。指标有效性、Tanimoto<0.5、scaffold MCS<0.65、interaction similarity>0.75、binding probability>0.7以每题原task.yaml为准。基础设施错误单列，保留52题分母。

结果：runs/{deepseek,chatdrug,agentdrug}/{task}/；评分：evaluation/{method}/{task}/result.json；完整请求响应：各题api/。每种方法独立文件锁，可跳过已完成任务；出现API/执行错误停止该方法等待修复，不自动更改配置。
