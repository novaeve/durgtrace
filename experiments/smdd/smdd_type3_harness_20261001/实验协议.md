# SMDD Type3 — MolClaw / Codex 补充实验

保留原有 baseline、ChatDrug、AgentDrug 结果。新增两组与基础 baseline 对齐公共配置，不声称旧五组已成为严格同预算实验。

共同条件：官方 SMDD-Bench 359ef1d7c042b85fc1c544662b4fd6fb381f346f，52 题；同一 obfuscate_task 公共输入 complex.pdb、reference.sdf；同一任务描述、solution.smi 输出及官方五项评分；无效分子计错，基础设施错误单列。

所有实际推理请求由公共边界发往原 baseline 的同一百炼端点：deepseek-v4.1-flash，enable_thinking=true，reasoning_effort=high，temperature=1。不添加单次输出 token 上限。每题累计输入+输出 1000 万 token、最多 100 次模型调用；原生 harness 的附属模型请求也计入。API 原始请求和响应、工具轨迹保存在控制目录，密钥不写入记录、不进入 agent 沙箱。

科学工具通过 MCP 暴露 baseline 原版 python、predict_boltz、predict_admet、submit；复用同一 Executor、Python rootfs 和包、Boltz/ADMET 实现，预算分别 8/15 次，随机种子 42，默认 10 个结构及 affinity 样本。为避免已确认的 RTX 5090 OOM，Boltz 最大同时采样设为 1，并启用 expandable_segments；不改变样本数、精度、分子、指标或阈值。原始 baseline 初始部署同时采样为 2，OOM 重评已使用上述配置。

MolClaw 使用服务器 Type2 相同安装中的原生 Claude CLI、MolClaw 原始 _build_prompt 和原始 skills。为对齐科学工具，不启用额外 SCP 工具，保留 Read/Glob/Grep/Skill 原生文件与技能工具。Codex 使用 Type2 原生 CLI 二进制，禁用额外 shell、网络搜索、apps、多代理，接入相同 MCP 科学工具。原生系统提示、上下文管理、文件工具和 MolClaw 技能是保留的 harness 差异，因此此实验属于公共科学工具对齐的适配版，不能表述为完整原生工具配置复现。

模型协议转换：已安装 LiteLLM 负责原生 Responses / Anthropic 协议到 Chat Completions 的转换；公共边界强制模型和 high、执行预算并保存实际请求。benchmark 科学 Python 在无网络沙箱内执行；CLI 只挂载公开工作区和必要可执行文件，不挂载答案、评分器或私钥。原生 CLI 的宿主网络命名空间仅用于本地模型/MCP 通信；网络工具与 shell 不暴露给模型。

运行目录 /data2/chenfuxin/smdd_type3_harness_20261001。smoke 为不计分连通验证，runs 为正式生成，evaluation 为官方评分，所有失败小测单独保留。每组先验证，再启动正式任务；后台任务遇到推理基础设施错误停止并记录。
