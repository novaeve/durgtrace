# MolClaw 四项基准

S²-mini MolEdit 1500、MolCustom 1500；MolLangBench Editing 400、Generation 400，共3800题。复用服务器现有冻结题目及官方评价实现。MolLangBench 采用 test/core 200 + extended 200，不含 supplement；参照最新 no_rules_v2 对照，不引入此前已撤回的手写题意反馈。

原生 MolClaw CLI、both 提示、原生 skills 与 SCP 工具。deepseek-v4.1-flash，独立 LiteLLM 代理固定 temperature=0、enable_thinking=false，两个并发实例。提示完整保留题意，仅把 MolLangBench 输出标签改为原生 <answer>；单题独立工作区。生成任务不初始化起始分子，不新增手写反馈或择优。标准答案、其他方法结果、私钥和认证文件不挂载到原生工作区。宿主 MCP 网关注入认证，复用现有 HTTP 实现。

按原生工作流结束；30分钟无原生事件输出记 stalled，后续题目继续。单题错误、无效或无最终提交都计入原分母，不按评分重采样。每题只收唯一最终分子；不从工具轨迹或历史答案择优。保留原始事件、stderr、最终输出、usage和耗时。

S² 复用 benchmark.evaluate 的官方精确条件与 MolEdit 相似度统计。MolLangBench 在独立评分进程读取答案，保持官方立体敏感 canonical SMILES 完全一致率，同时报告官方有效率和非空有效率。评分不回传模型。不用 PMO 的1000次预算或 AUC。

先六个 S² 子类及四个 MolLang 任务/split 各一题，共10题运行试验；仅按基础设施/运行状态检查，不按正确率决定全量启动。随后独立跑3800题，试验不混入正式结果。所有结果保存在本目录 runs/{pilot,full}。
