# SMDD Type2 跨任务迁移，2026-09-29

## 范围与比较口径

沿用 Claude baseline 的 25 道 Type2 任务，共 75 个预测点。DeepSeek v4.1 Flash 使用原 trace-harness-v1.2 工具循环；ChatDrug、AgentDrug 只做用户批准的 CSV 输入输出及格式检查适配。不能把它们说成相同工具架构的消融：baseline 有 Python/结构分析工具，两个分子编辑 agent 原生没有通用工具循环。

三者看到相同公开题干与经原 obfuscate.py 去标识的完整 receptor.pdb。baseline 通过原 Python 工具读文件，两个编辑 agent 通过文本收到文件。完整坐标不裁剪，不预先提取药效团、残基候选或专家特征。文件呈现方式不同，必须在结果中披露。CSV 为三行 x,y,z,type，无表头。两编辑 agent 使用相同任务提示与格式，不再要求 ChatDrug 生成五份分子。

## 预算及原生流程

DeepSeek baseline：原 AgentConfig，max_turns=100，max_tokens=10000000（累计输入加输出），boltz_budget=8，admet_budget=15，temperature=1，python_timeout=300，boltz_timeout=1800，admet_timeout=60，seed=42。只更换模型后端与部署基础设施。仍由原 submit 工具结束，答案只在运行后评分。

ChatDrug：原 conversation/ReDF，最大三次生成；CSV 解析替换 SMILES 解析；CSV 格式有效性替换 SMILES 合法性。完整任务正确性未知，不增加成功规则。原分子参考库无法认证药效团点，因此沿原无参考退出路径提交当前结果，通常一次调用。

AgentDrug：沿用冻结 core 的生成、修订、最后提交；仅将 SMILES 格式处理替换为 CSV 格式检查，删除不适用的分子属性评价块。采用作者单任务四次生成上限（此任务映射属于本次配置），保留 256 token 上限。修订只反馈行数、列数、有限数值与允许类型，不反馈距离正确与否或口袋几何。没有模型自主终止机制。

两个编辑 agent 模型也使用 temperature=1，与 baseline 一致。输出上限保留原 agent 参数并独立记录截断，不改好结果、不预设成功或失败。

## 评分与隔离

使用冻结 metrics/pharmacophore_3d.py 原函数：类型兼容的 Hungarian 匹配，距离严格小于 2.5 Å，输出 n_correct/3；三点全中才通过。报告点正确率（分母75）及全题通过率（分母25），格式失败和运行失败单列但不移出分母。

ground_truth.json 只由独立离线评分进程读取。仅将公开 receptor.pdb 放入 agent Docker；不挂载宿主文件夹、密钥、答案。编辑 agent 推理 audit hook 禁止访问 ground_truth.json。标准答案不用于选候选、调提示或反馈。

## 环境准备状态

旧服务器保留相同 smdd-agent 镜像 856965e37f2f，但无 GPU；新服务器有 GPU，无 Docker socket 权限。拟保留旧 Docker 的 Python/ADMET 环境，并将原工具生成的 Boltz 命令送到现服务器已配置的 Boltz GPU 环境，保留参数、返回结构和预算。该环境转发需要 smoke 验证后方可正式运行。

迁移曾被自动审批拦截，用户随后明确授权“允许迁移并严格隔离”。已完成迁移。答案仅供独立 score.py 使用；凭据目录0700、文件0600；模型代码只在无宿主目录挂载的旧 Docker 内执行。两个编辑 agent 已通过同一题运行及评分检查，正式批次复用首题后续跑剩余24题。

部署差异：DeepSeek API 调用由 requests 直接连接百炼的 OpenAI 兼容端点，再转成冻结 harness 原有响应对象；enable_thinking=false，无新增输出 token 上限，temperature=1；请求、响应和重试逐次记录。原 Python/ADMET 工具在相同镜像内执行，Boltz 命令保留参数，切换到现服务器兼容 RTX 5090 的已安装 Boltz 环境。此环境差异须披露，不能声称运行环境逐字节相同。
