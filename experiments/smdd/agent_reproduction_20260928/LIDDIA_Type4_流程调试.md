# LIDDIA Type4 流程调试

## 已修复

- 动作解析支持字段间空行，读取最后一个独立指令块；格式错误反馈给下一轮。
- CODE 提示保留原任务描述，修正原模板无参数名的 Python 函数示例及错误代码围栏，列出实际输入集合及列名、可导入库。明确使用已提供的 SAScore/Similarity，不能为缺失测量编造值。
- CODE 描述引用了未传入的集合时，在生成代码前返回明确错误，由模型自行补全 Input；不暗中添加集合或代选分子。
- CODE 的每次重试接收上一份源码和实际错误，不再重复无反馈的同一请求。仍最多三次，每次计入 LLM 预算。
- CODE 重试耗尽、执行超时、输入 ID/索引错误返回决策循环。空 DataFrame 合法。返回分子必须来自该次输入集合；回到主流程后物性从可信计算/测量缓存重新填充。
- 目标检查回复缺少格式时返回错误，不因正则索引越界退出。

保留隔离环境和导入白名单、Vina 禁用、ADMET 15 / Boltz 8 共享预算；没有更换任务目标或添加优化策略。此为 SMDD 适配层流程修复，非未修改的上游 LIDDIA。
