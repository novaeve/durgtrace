# MolLangBench 无手写题意规则重测 v2

用户授权：撤除题意检查，沿用原生编排和工具能支持的路径；不新增模型自主停止机制。

范围：Editing 400、Generation 400；ChatDrug 和 AgentDrug 各 800。原实验保留，不覆盖。模型仍为阿里百炼 deepseek-v4.1-flash，temperature=0、enable_thinking=false。首轮提示、原生解析、token 设置和上一版一致。

## 推理与停止

- 完全撤除手写题意规则、标准答案反馈和部分条件参考筛选；只做 RDKit SMILES 解析有效性检查。有效不等于满足题意。
- ChatDrug：执行冻结的原生 conversation/ReDF/parse_molecule；轮数上限 3。任务正确性未知时返回 None，不伪造成功。没有能够验证正确的参考分子，检索接口报告不可用，沿原生 ReDF 无参考退出路径结束，提交最后解析选中的候选。因此通常一次生成即结束。这属于移除任务 oracle 的消融，不能声称完整 ReDF 检索能力仍被使用。
- AgentDrug：保留冻结 core 的生成、有效性反馈、下一轮提示构造、最终输出处理；把原性质评价/参考检索块替换为有效性信息及“题意正确性未评价、无已验证参考”。不添加提前成功判断或模型自主提交。保持上一版 Editing 4、Generation 5 次生成上限；此任务到轮数的映射是此前适配配置，不是作者规定的 MolLangBench 默认值。仍使用作者 256 token 参数。
- 不提供随机/未验证参考冒充正确示例；不新增搜索、记忆、初始化或择优。ChatDrug 原生无效/空解析终止行为保留，AgentDrug 无效反馈修订保留。
- 推理进程 audit hook 禁止打开 answers.json 和 parquet。最终独立 score.py 才读取答案，沿用官方解析及 canonical SMILES 严格匹配。

每题保存 API 请求、响应、耗时、用量、原生轨迹、停止原因及最终唯一提交。配置保存脚本及题目哈希，最终分母每任务固定 400。没有答案指导下的调参或候选择优。
