# ChatDrug / AgentDrug × S²-mini MolEdit / MolCustom

用户确认使用各 1,500 题的 mini 子集。六个官方 CSV 各 500 条；每方法 3,000 题，合计 6,000 实例。数据来源 phenixace/S2-TOMG-Bench-mini，固定 commit、文件哈希见 data/manifest.json。模型沿用阿里百炼 deepseek-v4.1-flash，temperature=0，enable_thinking=false。

## 任务接口及原生流程

- 起始指令逐字使用 CSV Instruction。MolEdit 自带输入分子；MolCustom 不提供起始分子，直接从任务约束生成，不额外调用模型初始化，不加入搜索、跨题记忆或人工起点。
- ChatDrug 直接执行上游 main_ChatDrug.py 的 conversation、ReDF 与 utils.py 的 retrieve_and_feedback。保持 C=2、最多三次生成、原始五候选提示、原解析器及 trial_index=0。只评价原解析器选中的第一项；成功停、解析空停、找不到满足条件的检索分子即停。原解析器的最小长度、排除输入和上轮参考分子规则保留。
- ChatDrug 的判定接口替换为 S² 官方精确条件；参考库仍为作者 ZINC250K 过滤原始200输入后 seed=0 抽取10,000条。全部参考分子按作者 Morgan count fingerprint 半径2的相似度排序，返回首个满足任务条件的分子；预计算描述符仅缓存不改变排序或筛选。无相似度硬门槛。
- AgentDrug 执行此前审计的 core_fixed.py，仅将属性判断和属性反馈块替换为 S² 精确计数条件。保留有效性反馈、满足条件的参考库过滤、相似度检索、每轮以原始指令加最近输出及反馈构造下一轮、原终止分支及最后轮直接输出。参考库是作者 AgentDrug-datasets/ZINC500/database.csv，shuffle seed=42，前10,000条。
- AgentDrug 原配置单条件最多4轮、多条件最多5轮；这里将1个计数条件映射为4轮、多个计数条件映射为5轮，这是新增任务的明确映射。保留作者生成上限256 token，不为ChatDrug另加token上限。AgentDrug输出格式提示改为“your molecule”以同时覆盖生成和编辑任务。
- 这是将原生 agent 流程接到新任务的接口适配，不声称作者程序原本支持 MolCustom。MolCustom 无原分子，所以属性反馈使用目标绝对数量，而不是虚构原分子性质。

## 评价与故障

- 每题一个最终分子。ChatDrug 使用最后一次原解析器选中的分子，若该次解析为空则无答案；检索失败仍记录模型已选出的失败候选，绝不回退择优或把检索库分子充作模型答案。AgentDrug 使用原核心返回的唯一 pred。
- MolEdit 增加/删除指定官能团数恰好1；替换任务同时满足减1、加1。Morgan bit vector radius2 / 2048 Tanimoto仅报告相似度，无阈值。
- MolCustom 原子数及官能团数包括零值全部精确匹配。BondNum 按官方实现忽略目标为零的键型。FunctionalGroup 的 mini 数据列 benzene_ring 对齐官方评价器 benzene rings；CSV 的 thioether 列不在官方评价器的检查列表内，照原逻辑不额外加入。
- 报告全体题目的成功率与有效率、MolEdit 有效输出的平均相似度。错误单独统计，不能从分母静默删除。无 AUC、PMO oracle 限额或私加相似度限制。可选 novelty 尚未计算，不将 SR 冒称 WSR。
- API仅对传输及临时HTTP错误重试，同一请求缓存并可断点重放；不因低分、重复或无效输出额外采样。保存全部调用文本、模型标识、usage、finish_reason及耗时，不保存认证头。
- 先每方法每子集2题，共24个pilot实例；评分与上游真实评价分支交叉校验通过后，独立tmux长程运行。两方法各4线程，保留已有其他实验。
