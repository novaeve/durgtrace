# ChatDrug / AgentDrug：模型生成起点，原生单次编辑流程

2026-09-25 用户授权：用模型自行生成起始分子，保持和 DeepSeek 对照组一样的初始化。

每个 PMO 目标共用 DeepSeek 对照组的第一个模型答案，不择优，不挑第一个有效答案；若该目标还没开始，就用完全相同的对照组 runner 产生它的第一次答案，保存后复用。模型生成起点在每个方法自己的提交账本中占第 1 次，后续生成答案包括重复、无效均计提交。起点若无效则记录初始化失败，不另抽一个补救。

ChatDrug 保留原 conversation / ReDF / parser / 相似检索 / 最多 3 次生成；AgentDrug 保留此前披露修复后的 core_fixed 有效性、性质反馈和参考检索、最多 4 次生成、作者 256 输出上限。将原性质评价接为 PMO 标量且要求高于起点，是任务评价接口变更，不是增加搜索策略。不会在编辑结束后继续重启、追加父分子选择或跨轮记忆。因而正常结束时通常只提交 2–4 / 2–5 次，而非承诺用完 1,000 次。

检索机制需要各自的固定语料。ChatDrug 按原 loader 规则从 ZINC250K 中排除原编辑输入后采样 10,000 条、seed=0；AgentDrug 从作者官方数据集 ZINC500/database.csv 按原 GenerationDataset random_state=42 打乱并取 10,000 条。保留这两种检索机制，不将库替换成跨轮搜索档案。AgentDrug 官方原库本次新下载，来源和 SHA256 见 native_data/agentdrug_database_source.json。

预算为答案提交数，不是 oracle 次数；内部反馈与参考库评分逐次独立记录在 oracle_access.jsonl / oracle_evaluations.jsonl，不能声称 oracle-1K。参考库评分不自动成为答案或纳入答案 AUC，也不据此选择初始分子。

自然结束单独标为 native_finished，budget_exhausted=false。同时报告观察区间 AUC 及 MT-Mol finish=True 持平补尾 AUC，明确未用完预算，不把自然结束冒充 1,000 次完成。模型初始化的原始 API 记录在对照组；编辑组 usage 为新增实际 API 消耗，初始答案的复用另行标记。

MolLingo 的过往 ChatDrug/S² 运行通过 runner.py::core_namespace 调用 optimize_mol_tomg，执行基准给定起点上的片段编辑与重组；未使用 run_agent.py → planner.py → agent.py 完整药物发现流程。完整入口缺少 agent.py 不影响该编辑工具，但不能把工具实验称为完整多 agent 编排实验。此次没有自行补写 agent.py，也没有启动一个替代的 MolLingo 完整流程。
